# Designing a Map

<Box>

Maps are complex, filled with many different things. Therefore, it needs a powerful tool to design them.
That's why we use [Tiled](https://www.mapeditor.org/).

</Box>

<Box>

## Installing Tiled
---

Tiled is available for all major platforms. You can download it from [here](https://www.mapeditor.org/). There's no Kristal extension for Tiled yet, so that's all you need to do.

</Box>

<Box>

## Opening Your Project
---

Once you've installed Tiled, you can open your project. You can do this by clicking on `File`, and then `Open File or Project`.

<>![](/wiki/designing-a-map/tiled_open.png)</>

Now, navigate to your project's folder. You should find a file called `<your-project>.tiled-project`. Open it.

The project window on the left should now show a folder tree. This is your project. You can open any map by double-clicking on it! Feel free to mess around with them!

</Box>

<Box>
## Creating Tilesets
---

These are the default maps and tilesets.

<>![](/wiki/designing-a-map/maps.png)</>

First, we need to create a tileset. A tileset is, as the name suggests, a set of tiles. Every map is made up of tiles! Let's use this one:

<ScaledSprite src="/wiki/example_tileset.png" name="example_tileset.png" width={120} height={80} scale={2}/>

It's... not the greatest, but it'll get the job done.

This tileset's tiles are **20 pixels wide and 20 pixels tall**. We'll refer to that size as **20x20**.

<NoteBox type="important">
    You can use any size you'd like, but most of DELTARUNE's tilesets are 20x20, upscaled to 40x40. We'd **heavily recommend** using 20x20.

    We can let Tiled upscale the tiles for us, and we'll go over that further down.
</NoteBox>

Let's save this in the folder `assets/sprites/tilesets`, as `example_tileset.png`. **It's very important that you use this directory for your tileset images.**

Now, let's create the tileset.

<>![](/wiki/designing-a-map/new_tileset.png)</>

Let's name it `example_tileset`. The tile width and height should be `20`, and the margin and spacing should be `0`. Click browse, and locate the tileset image we just saved. You should have the following settings:

<>![](/wiki/designing-a-map/new_tileset_filled.png)</>

Click **Save As...** and save it to `scripts/world/tilesets` as `example_tileset.tsx`. **It's also very important that you use this directory for your tilesets.**

Now that the tileset is created, we need to do one last step. Open the tileset properties.

<>![](/wiki/designing-a-map/tileset_properties.png)</>

Change **Tile Render Size** to `Map Grid Size`. This will make the tiles render at the size we want them to. Now, click **Save**.

<NoteBox type="note">
    This'll make our 20x20 tiles from earlier stretch to 40x40, which is exactly what we want.
</NoteBox>

Once everything's saved, press `CTRL+E` to **export** the tileset. You have to export it every time you make a change to it, otherwise the changes won't be applied.

Make sure to export it as a `.lua` file in the same directory as the `.tsx` file. So, in this case, `scripts/world/tilesets/example_tileset.lua`.

<NoteBox type="important">
    You must export it as `.lua`. Renaming is not enough!
</NoteBox>

If you get tired of having to export after every save, you can enable this in the preferences:

<>![](/wiki/designing-a-map/preferences.png)</>

But anyway, we have a tileset now! So why don't we create a map now?
</Box>

<Box>
## Creating a New Map [new-map]
---

Now that we've made a tileset, we can start making maps!

Create a new map by going to `File`, then `New`, then `New Map...`.

- Make sure the orientation is `Orthogonal`,
- The tile layer format is `CSV`,
- and the tile render order is `Right Down`.

We want our tile size to be `40x40`, since that's what DELTARUNE's maps use. If your tileset is smaller than that (like the one we made earlier, which is 20x20),
it will be automatically stretched (because of the settings we changed earlier).

The map size should be **Fixed**. For now, we'll make a map with a width of `16`, and a height of `12`.

<NoteBox type="note">
    You can make maps larger than this, but for this tutorial, we'll just stick with 16x12.

    It's not recommended to make a map smaller than 16x12, as anything smaller would be smaller than the screen.
</NoteBox>

After making sure all of that is set, click **OK**. Congratulations, you now have an empty map!

---

The first thing we'll want to do is to save.

Go to `File`, then `Save As...`. Save it to `scripts/world/maps` as `example_map.tmx`.

<NoteBox type="important">
    You **must** save it in `scripts/world/maps`. This is where Kristal will look for maps.
</NoteBox>

Make sure to export it as a `.lua` file in the same directory as the `.tmx` file. So, in this case, `scripts/world/maps/example_map.lua`.

<NoteBox type="important">
    You must export it as `.lua`. Renaming is not enough!
</NoteBox>

Now, you can place down tiles! Make anything you'd like, and don't forget to keep saving! Here's what I made:

<>![](/wiki/designing-a-map/example_map.png)</>

It's... a huge bone? I don't know. It's not important. What is important is that you save your map, and that you're happy with it.

</Box>

## Layers
---

Kristal needs to know what you intend to do with each layer.

Tiled itself has a few layer types, the most important ones being Tile Layers and Object Layers.

Tile layers can be used as-is, but Object layers in Kristal need to be marked as a specific type.

Read the [Map Layers](/wiki/map-layers) page to learn more about the different layer types, and how to set them up.

</Box>

<Box>
## Markers
---

Markers are "points" in a map, which can be used for many different things.

They're used to mark things like spawn points, and general points of interest.

First, let's make a new markers layer.

<CollapseBox title="How to make a markers layer" defaultopen="false">
    Create a new object layer, and set its class to `markers`. You can name it whatever you want, but make sure that you'll understand it later!
    <>![](/wiki/designing-a-map/new_object_layer.png)</>

    Us Kristal devs really like when they're purple (it helps us know the layer at a glance), but you can make them any color you want.

    <>![](/wiki/designing-a-map/purple_color.png)</>

    Further information on layers can be found in the [Map Layers](/wiki/map-layers) page.
</CollapseBox>

To place down a point, use the Insert Point tool, which you can find in the toolbar at the top, or by pressing `I`.

<>![](/wiki/designing-a-map/insert_point.png)</>

Now, click anywhere on the map. A point should appear.
This is a marker! We're trying to make the player's spawn point right now, so name it `spawn`.

<>![](/wiki/designing-a-map/example_map_with_spawn_marker.png)</>

Now, let's test in-game! Save and export your map.

<NoteBox type="note">
    Loading your project may show you an error...
    <CollapseBox title="View error" defaultopen="false">
        <>![](/wiki/designing-a-map/room1_error.png)</>
    </CollapseBox>

    ...or spawn in a different room.
    <CollapseBox title="View room" defaultopen="false">
        <>![](/wiki/designing-a-map/room1.png)</>
    </CollapseBox>

    You can fix this by changing the map that Kristal loads into.

    <CollapseBox title="Changing the default map" defaultopen="false">
        Open `mod.json` in your project folder. You should see a line that looks like this:

        ```json
        "map": "room1",
        ```

        Change it to the name of your map, which in this case is `example_map`. It should now look like this:

        ```json
        "map": "example_map",
        ```

        Save the file, and try again!
    </CollapseBox>
</NoteBox>

As you can see, we've now successfully spawned at the marker we placed!

<>![](/wiki/designing-a-map/working_spawnpoint.png)</>

Now, select the **Insert Rectangle** tool, which you can find in the toolbar at the top, or by pressing `R`.

<>![](/wiki/designing-a-map/insert_rectangle.png)</>

This is one of the tools you'll be using to draw collision. It's pretty simple, just click and drag to make a rectangle. **Make sure to hold `CTRL` to make it snap to the grid!**

### Slopes, Polygons, and More

Using the **Insert Polygon** tool, which you can find in the toolbar at the top, or by pressing `P`,
you can make any polygon you want! Whether it's a triangle, a trapazoid, or even a pentagon, you can make it!

Holding down `CTRL` makes it snap to the grid, as well, so you can make perfect shapes!

## Placing Objects
---

Most of what you'll see in rooms are **objects**. Most things in Kristal are objects!

### Using Objects

To use an object, we need to first make a layer for them.

First, make an "objects" layer.

<CollapseBox title="How to make an objects layer" defaultopen="false">
    Create a new (Tiled) object layer, and set its class to `objects`. You can name it whatever you want, but make sure that you'll understand it later!
    <>![](/wiki/designing-a-map/new_object_layer.png)</>

    They're usually pink.

    <>![](/wiki/pink_color.png)</>

    Further information on layers can be found in the [Map Layers](/wiki/map-layers) page.
</CollapseBox>

Kristal Objects can be placed through using one of the Tiled object placement tools. Most of the time, you'll be using either **Insert Rectangle** or **Insert Point**.

Once you've placed down a Tiled object (for this example, we'll use a **point**), you can change its properties in the properties panel.

To select which object you want to use, change the `class` field (or `name` field, if you want it to show up in the editor) to the name of any [registered "event"](/wiki/using-events).

Let's name it `chest`, which'll spawn the [TreasureChest](/wiki/api/TreasureChest) object.

Let's now add the `money` custom property (making sure it's an `int`) and set it to `999`. This'll give us a lot of money when we open the chest!

<>![](/wiki/chest_properties.png)</>

If we save, export, then open up our project in Kristal, we should see the chest! And interacting with it should give us **999 Dark Dollars**! Wow!

### Room Transitions

Room transitions are rectangular objects, called `transition.`

Normally, you'll want to set the `map` and `marker` properties (to go to a marker in another map).

You can use the `facing` property to make the player face a certain direction when they spawn in the new map; otherwise, they'll just face the direction they were facing when they left the previous map.

You can read more about room transitions on the [Using Events](/wiki/using-events#transitions) page.

### Creating Events

<NoteBox type="warning">
    The information in this section is **outdated**, and will be rewritten and moved in the future.

    In modern Kristal, Events are just made in the Objects folder, and registered through `Game:registerEvent()`.

    <CollapseBox title="Sample" defaultopen="false">
        ```lua
        function Mod:init()
            -- Register our custom events

            Game:registerEvent("mycustomevent", function(data)
                return MyCustomEvent(data.x, data.y, { data.width, data.height })
            end)
        end
        ```
    </CollapseBox>
</NoteBox>

Events are just [objects](/wiki/objects) which extend the [Event](/wiki/api/Event) class. You can make your own events by creating a new file in `scripts/world/events`, and extending the `Event` class. Let's make an event which is... a pinwheel! And let's make it spin when you interact with it!

Here's the sprites I made, although they're not very good:

<ScaledSprite src="/wiki/pinwheel.png" name="pinwheel.png" width={12} height={12}/>
<ScaledSprite src="/wiki/pinwheel_base.png" name="pinwheel_base.png" width={20} height={20}/>

And here's the code I ended up making:

```lua
-- Extend the Event class, and set the ID to "pinwheel"
-- This is what you'll use to refer to the event in Tiled
local PinwheelEvent, super = Class(Event, "pinwheel")

-- `data` is the data directly from Tiled
function PinwheelEvent:init(data)
    -- Place the event at the correct position, and make the size 20x20
    super.init(self, data.x, data.y, 20, 20, data)

    -- Any custom properties are stored in `data.properties`, but we don't use any.

    -- Just some variables for the pinwheel
    self.min_speed = 2
    self.speed_slowdown = 0.5
    self.speed = self.min_speed
    self.pinwheel_rotation = 0

    -- Most events in DELTARUNE are 2x sized
    self:setScale(2)

    -- We placed a single point in Tiled, which we want to be the bottom center of the pinwheel
    self:setOrigin(0.5, 1)
end

-- Update gets called every frame
function PinwheelEvent:update()
    super.update(self)

    -- Make it rotate using the speed
    self.pinwheel_rotation = self.pinwheel_rotation + (self.speed * DTMULT)

    -- If it's going too fast, slow it down
    if self.speed > self.min_speed then
        self.speed = self.speed - self.speed_slowdown * DTMULT
    end

    -- Make sure it doesn't go below the minimum speed
    self.speed = math.max(self.speed, self.min_speed)
end

function PinwheelEvent:draw()
    super.draw(self)

    -- First, draw the base
    love.graphics.draw(Assets.getTexture("pinwheel_base"), 0, 0, 0, 1, 1)
    -- Then draw the pinwheel, spinning
    love.graphics.draw(Assets.getTexture("pinwheel"), 10, 10, math.rad(self.pinwheel_rotation), 1, 1, 6, 6)
end

-- When we interact with the pinwheel, make it spin faster!
function PinwheelEvent:onInteract()
    self.speed = 60
end

return PinwheelEvent
```

Then we just have to place it somewhere, using the ID we supplied in the code, `pinwheel`!

<>![](/wiki/pinwheel_placed.png)</>

After all this, we have our own event!

<>![](/wiki/pinwheel_spin.gif)</>
